Create an order:

curl --header "Content-Type: application/json" \
  --request POST \
  --data '{
    "items": [
      {
        "name": "Produto A",
        "quantity": 2,
        "price": 50.0
      },
      {
        "name": "Produto B",
        "quantity": 1,
        "price": 30.0
      }
    ]
  }' \
  http://127.0.0.1:8000/orders

  Cancel an order:

  curl --header "Content-Type: application/json" \
  --request POST \
  http://127.0.0.1:8000/orders/{order_id}/cancel
